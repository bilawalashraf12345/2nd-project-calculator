# Smart Calculator

This is a modern Multi-Function Calculator made using HTML, CSS and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Square
- Clear and Delete buttons
- Modern Design
- Responsive Layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Open the project in VS Code.
2. Keep all files in the same folder.
3. Open `index.html` in your browser.
4. Use the calculator.
